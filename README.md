# token-miser

给 AI agent 的省钱技能：输出 token 要花钱，这套规则让模型少说废话、少绕弯、多复用已读内容。

用户规则来自实盘调优，包含三条核心洞见：

1. **输入比输出便宜十几倍** —— 多读文件验证，少自言自语；思路优先从已读内容里找，别一有问题就搜网。
2. **突破进展三问** —— 有了"妙招"先别顺着推：找更简洁的方法 → 成功就重复，失败才沿用。防自嗨式局部最优。
3. **禁止废话税** —— 不总结刚做过的事、不客套、不复述需求，代码能表达就用代码。

## 安装

方式 A：常驻（每个会话自动生效，推荐）

把 `AGENTS.md` 内容放到 agent 的全局指令文件（如 Claude Code / dsh 的 `~/.dsh/AGENTS.md` 或项目根 `AGENTS.md`）。

方式 B：按需技能

把 `SKILL.md` 放进 skills 目录（如 `~/.dsh/skills/token-miser/SKILL.md`），说"少废话 / 省着点"触发。

## 实测数据

两个难度相近的任务，同一模型/环境，各跑一次（n=1，仅供参考）：

| 维度 | 有 Skill | 无 Skill | 变化 |
| --- | ---: | ---: | --- |
| 轮次 / 步数 | 5 轮 / 42 步 | 4 轮 / 40 步 | 相近 |
| LLM 耗时 | 3 分 48 秒 | 20 分 44 秒 | **-81.7%** |
| 工具耗时 | 21 分 27 秒 | 12 分 44 秒 | +68% |
| 总墙钟 | 25 分 15 秒 | 33 分 28 秒 | -24.6% |
| 首 token 延迟 | 1.3s | 1.4s | 相近 |
| 生成速度 | 89 tok/s | 77 tok/s | 波动，勿过度解读 |
| 缓存命中率 | 97% | 98% | 相近 |
| 输入令牌 | 2.5M | 3.7M | -32.4% |
| 输出令牌 | 15.5K | 91.8K | **-83.1%** |

诚实解读：

- 输出是主要成本（贵），省 83%；输入基本全走缓存（便宜），再省 32%。
- LLM 思考时间省 81.7%：少自问自答、少绕弯，token 少了，思考也短了。
- 有 Skill 时工具耗时反而更长——少说多做的代价是更多次实操验证（读写文件代替自言自语）。按"输入便宜、输出贵"的原则，这笔交易划算。
- 生成速度 89 vs 77 tok/s 与输出长短无关，属服务端波动，不作为卖点。
- n=1 样本，数据仅证明方向，不保证幅度。
